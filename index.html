01

What does minSdk mean?

minSdk is the lowest Android API level on which an application declares that it can run. Android compares this value with the API level provided by the device. If the device level is lower, the system normally prevents installation because the required platform APIs are unavailable.

02

How should you read the result?

A passing comparison means only that the device meets the declared minimum platform version. It does not confirm hardware support, available storage, CPU architecture, regional availability, account requirements, or successful runtime behavior.

03

Where can the required values be checked?

Developers define minimum and target API levels in an Android project's build configuration. Published file records may also state the minimum Android version for a specific release. For a practical example, Subway Surfers Mod Game records the current file version, Android requirement, package identity, size, and SHA-256 together so the compatibility value can be read in context.

Important limitations

  • The checker uses values entered by the visitor; it does not extract data from an APK.
  • A compatible API level does not guarantee that every device feature required by an app exists.
  • targetSdk describes the platform behavior an app was designed and tested against; it is not the minimum installation requirement.
  • Some distribution services apply additional compatibility and policy filters.

Technical basis: Android Developers documentation for the <uses-sdk> element and API-level compatibility behavior.
